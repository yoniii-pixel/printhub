# PrintHub: Quality Printing Service

Business website for the Event-Driven Programming final project (BSIT 3 Section 4, Cebu Eastern College), based on the PrintHub feasibility study.

## Features (PyScript, `main.py`)
- **Live receipt builder:** `input` events recalculate prices as you type
- **Claim tickets:** `submit` creates a ticket; `click` marks it picked up
- **Service filter:** `click` tabs show All / Printing / Finishing
- **Competitor comparison:** `click` tabs update the details dynamically

## Run locally
`python -m http.server`, then open http://localhost:8000 (PyScript needs http, not file://).
